# BHID (Bottleneck Hazard Intelligence & Detection)

BHID is an AI-powered crowd intelligence system designed to analyze pedestrian movement and predict future crowd bottlenecks from CCTV and video feeds. By combining computer vision, machine learning, and an agentic orchestration layer, the system generates real-time risk scores, visualizations, alerts, and analytical reports.

> **Note:** The project is currently in the initial setup phase (Phase 0).
